# Git Version Control 

*Short summary:*
This repository contains my Module 3 assignments and shows basic Git workflows. 
---

# What is Git? 
Git tracks changes, supports branching/merging, and helps teams collaborate.

# How to use this repo 
- Put each assignment in its own folder (e.g., `assignment-1/`).
- Commit often with clear messages: `git add .` → `git commit -m "Brief, descriptive message"`.
- Push to the remote: `git push` and follow instructor submission instructions.

# Best practices 
- Make small, focused commits.
- Use a `.gitignore` to exclude generated files.
- Include a short `README.md` inside each assignment folder explaining how to run your work.
